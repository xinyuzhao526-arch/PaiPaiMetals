## 八、推荐的「权威优先级」工作流（以后更新复刻页）

1. **全球分母** → 只信 USGS MCS / ILZSG（铅锌）PDF
2. **交易所库存** → LME official stocks、上期所周报/仓单日报、CME/COMEX stocks（注意 short ton）
3. **矿山产量与指引** → 矿企 quarterly/annual production report、guidance 新闻稿
4. **资源储量** → Technical Report / Reserves and Resources 表（写明 cut-off、含金属量 vs 矿石量）
5. **事件** → 公司新闻稿 / 交易所公告，再允许行业媒体作索引
