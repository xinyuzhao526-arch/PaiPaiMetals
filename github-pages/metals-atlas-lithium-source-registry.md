## 口径说明

| 层级 | 单位 | 备注 |
|------|------|------|
| LCE | kt LCE | 碳酸锂当量；盐湖销售/集团锂常用 |
| 锂盐 | kt | 碳酸锂/氢氧化锂等产品吨，未必已折 LCE |
| 锂辉石精矿 SC / SC6 | kt SC | 硬岩精矿实物或 6% 当量吨，**不可与 LCE 直接加总** |
| 金属锂 | kt Li | USGS 矿山产；约 ×5.32 粗换 LCE 仅参考 |
| 中国碳酸锂 | kt 或 kt/月 | 产量与社库；非交易所仓单 |

**禁止**：SC + LCE + 锂盐 + 金属锂混加；Greenbushes 日历年与 IGO 财年混用。
